# Weather App

A simple weather application built with HTML, CSS, and JavaScript during the initial learning days.

## Overview

This project demonstrates fundamental web development skills by creating a functional weather application. The app provides weather information with a clean and intuitive user interface.

## Features

- 🌡️ Real-time weather information
- 📍 Location-based weather data
- 🎨 Responsive and user-friendly design
- 🌐 Built with vanilla HTML, CSS, and JavaScript

## Tech Stack

- **HTML** (27.7%) - Structure and markup
- **CSS** (39.7%) - Styling and layout
- **JavaScript** (32.6%) - Functionality and interactivity

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/srivastava-aryan/weather.git
   ```

2. Open `index.html` in your web browser

## Usage

Simply open the application and enter a location to view the current weather conditions.

## Project Purpose

This was built as a first project to establish foundational web development skills including DOM manipulation, API integration, and responsive design principles.
